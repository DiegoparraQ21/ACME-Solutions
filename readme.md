Filtro 1. Python - Desarrollo de un programa / gestor de contactos para la empresa ACME Solutions con el fin de sistematizar, registrar, buscar, listar, actualizar y eliminar tanto los usuarios que hacen parte de la empresa cuyos roles pueden variar entre administradores u operarios y asi mismo los contactos que vendrian siendo clientes, proveedores, etc.
-------------------------------------------------------------------------------------------------------------------------
---APP--- Dentro de APP se establece el main del proyecto donde se importan todos los modulos como (core, crud_contacts, crud_users, messages, utils y agenda) para tener acceso a cada una de las funciones creadas, tambien se define el diccionario principal ORIGIN, en el cual se encuentran todos los datos que se iran almacenando como los usuarios que hacen parte de la empresa y los contactos, junto con la llamada de MY_DATABASE en el archivo agenda.json en la carpeta data y se realiza el checkfile desde el core para verificar que el archivo existe y cargue los datos o sino que cree un archivo nuevo. Luego se pide al usuario que ingrese al sistema con sus credenciales corporativas las cuales serian su email y clave, donde se emplea un ciclo while para que el programa permanezca en ejecucion hasta que el usuario decida cerrar la sesion, de igual manera se agrega un try para que solo sea permitido el ingreso de datos enteros, asi mismo una vez logueado el usuarios el sistema verifica su respectivo rol con el fin de mostrar un menu, si el usuario registrado es un administrador, se llamara del modulo de messages al menu_principal_usuarios_admin; o si es un operador del mismo modulo de messages al menu_principal_usuarios_noadmin, posteriormente se establece el match con el fin de acceder a cada una de las opciones del menu, adicional se agreda un case any(_:) donde se le indica al usuario que el numero ingresado es incorrecto si el valor es diferente a las opciones que se presentan en el match y finalmente se cierra con un except donde se le indica al usuario que el dato ingresado debe ser un numero entero en caso de que sea un valor diferente.
-------------------------------------------------------------------------------------------------------------------------
---CORE--- Dentro del core se importa el sistema operativo y el json con el fin de deifinir las funciones NewFile para crear el archivo, ReadFile para leer el archivo json almacenado, checkFile para verificar si el archivo existe lo lea y si no existe lo cree y AddData para guardar la informacion de los usuarios y de los contactos.
-------------------------------------------------------------------------------------------------------------------------
---UTILS--- Dentro de utils se crean las funciones para borrar y pausar pantalla con el fin de quer el programa se vea mas limpio al momento de ejecutar cada una de sus opciones.
-------------------------------------------------------------------------------------------------------------------------
---MESSAGES--- Dentro de messages se crean los mensajes principales a importar en los mudulos de acuerdo a las necesidades del programa.
-------------------------------------------------------------------------------------------------------------------------
---CRUD_USERS--- Dentro del crud_users se importan los modulos necesarios para la ejecucion del programa y de igual manera se crean todas las funciones que estan relacionadas con los usuarios, las cuales permitiran el inicio de sesion del usuario, el registro de nuevos usuarios, listar los usuarios, actualizar su informacion, eliminarlos y por ultimo cerrar la sesion.
-------------------------------------------------------------------------------------------------------------------------
---CRUD_CONTACTS--- Dentro del crud_contacts se importan los modulos necesarios para la ejecucion del programa y de igual manera se crean todas las funciones relacionadas con los contactos, las cuales permiten registrarlos, listarlos, buscarlos, actualizarlos y por ultimo eliminarlos.
-------------------------------------------------------------------------------------------------------------------------
---AGENDA--- Dentro de agenda se encuentra nuestro json el cual va almacenando toda la informacion correspondiente a los usuarios y contactos, el cual puede ser modificado por el usuario que se encuentre usando el programa.
-------------------------------------------------------------------------------------------------------------------------
---AUDITORIA--- Se implementó un módulo de auditoría de datos integrado al menú principal de la aplicación. Esta funcionalidad permite revisar la consistencia de la información almacenada en agenda.json sin modificar el archivo original. La auditoría valida usuarios y contactos verificando campos obligatorios, correos electrónicos duplicados en usuarios e IDs duplicados en contactos. Al finalizar, el sistema genera automáticamente un archivo reporte_auditoria_datos.json con el detalle de los errores encontrados y un resumen general de la revisión. También se manejó el caso en el que no existan errores, generando listas vacías y un mensaje indicando que los datos son correctos.
